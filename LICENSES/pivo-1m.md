# PiVo 1.4M

Optional research-quality two-voice model: https://huggingface.co/empero-ai/PiVo-1.4M
Model and runtime by Leon Lehmann / Empero Research, Apache License 2.0.

This Kotlin engine independently implements the upstream four-stage ONNX
inference algorithm and FARGAN-derived neural vocoder. The optional bundle
includes the upstream Apache-2.0 license, model card, third-party notices,
and the separate CMU Pronouncing Dictionary license. No PiVo weights,
phoneme dictionary, or bundled Python are embedded in the APK.
